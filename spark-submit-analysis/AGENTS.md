# AGENTS.md — Hexo Blog 项目规则

## 提交策略

- 多次修改（如文章内容 + 会话上下文 + 源码注释）**攒一起再提交**，不频繁提交
- 每次修改问用户"要不要提交？"（包含 hexo-blog 和 Flink/Spark 源码项目的提交）

## 编辑规范

- 涉及删除内容时，需在反馈中说明删了什么、改了什么、影响范围
- 使用 `git diff` 展示变更（贴在回复中）

## 写作规范

- 加粗规则：仅分类标题（如 `Join 场景`、`聚合场景`）可加粗，正文描述不加粗

## 源码项目权限

- Flink 源码项目（`D:\workspace\learning\flink`）直接申请**整个项目根目录**的权限
- 不需要限制到具体包路径
